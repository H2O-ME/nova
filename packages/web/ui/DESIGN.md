# Nova WebUI 设计规格

> 这份文件是 `packages/web/ui` 的**唯一 UI 规格入口**。改任何界面、样式、组件之前先读它，
> 再读 `AGENTS.md` 的架构白名单。它取代 2026-11-20 删除的 `docs/NOVA-DESIGN-SYSTEM.md`
> （原文仍可从 `.docs-archive/docs/NOVA-DESIGN-SYSTEM.md` 或 git 历史取回，但以本文件为准）。
>
> 为什么它不是一个"历史文档"：`scripts/ui-token-guard.mjs`、`ui/test/style-guard.test.ts`、
> `ui/test/motion-guard.test.ts`、`ui/test/palette-guard.test.ts` 四道守卫仍在机器执行下面
> 这些规则。规则必须有可读的住处，否则每次改样式都只能从红灯反推意图。

## 1. 最高优先约束（机器可检查，违反即缺陷）

1. **只消费 token。** `.ts`/`.tsx` 与 `*.module.css` 里的颜色、间距、圆角、阴影、时长、缓动
   只能通过 `var(--nova-*)` 取值。token 的唯一定义处是 `src/design/tokens/`。
2. **字面量是封闭清单。** 允许保留：`border-width`/`outline-width`、hairline 1px、
   icon size、SVG 绘制尺寸（`stroke-width`/`viewBox` 等）、特殊图形几何（环、进度条、画布坐标）。
   其余 `padding`/`margin`/`gap`/`border-radius`/`box-shadow`/`transition`/`animation`
   不得出现 px / ms / s / 缓动词 / `cubic-bezier()` 字面量。
3. **旧词表禁止出现。** `--dsw-*`、`--ds-*`、`--dsh-*` 一律不得再出现（`style-guard` 已翻转）。
4. **动效只动 `opacity` 与 `transform`。** 不重排、不重绘布局；共享 keyframes 只在
   `src/design/motion.css` 声明，`prefers-reduced-motion: reduce` 的钳制必须保持挂载。
5. **明暗两档都是一等公民。** 深色通过 `body[data-nova-dark]` 覆盖 token 值，组件不写
   `dark:` 分支以外的颜色；不允许只改亮色就交差。
6. **样式不写进 JSX。** 颜色/尺寸不写 `style={{ … }}`；组件样式只进同目录 `.module.css`。
   例外：`kit/Dialog` 的 `width`/`maxHeight`/`padding` 这类调用点几何参数。

## 2. 改样式先做三件事（决策树）

**第一步：分清"值不对"还是"结构不对"。**

- 颜色 / 明暗 / 层级 / 圆角梯度不对 → 改 `src/design/tokens/*.css` 的 token 值（一处改，全仓生效）；
- 间距 / 布局 / 尺寸不对 → 改使用方组件的 `.module.css`，从 token 阶梯里选最近的一档；
- 两者都不是 → 先查是不是组件用错了层（见第二步）。

**第二步：确定组件层（只有这四条路）。**

| 你要做的东西 | 放哪 | 规则 |
| --- | --- | --- |
| 跨页通用控件（弹窗、按钮、图标按钮） | `src/kit/` | 优先复用；新弹窗必须组合 `kit/Dialog` + `shell/modal-layer`，不自造遮罩/焦点陷阱 |
| 对话原语（气泡、消息行、附件、标记、滚动器） | `src/components/ui/` | shadcn 风格原语，仅服务 chat；**不新增通用原语** |
| 其余所有界面 | 各功能目录的 `*.module.css` | CSS Modules + token，一层目录一个 sheet |
| Tailwind 工具类 | `src/components/ui/` 内部 | 只服务该层；新组件不用 Tailwind 写样式 |

> 2026-11-21：`src/ui/`（Aceternity 极光/光晕层）已删除——全仓零消费者。不要再引入装饰组件层。

**第三步：要不要新增 token？**

先查 §5 的生成表。只有**同一语义第二次出现**时才新增；新增必须进 `src/design/tokens/*.css`，
命名走语义（`--nova-space-*` / `--nova-radius-*` / `--nova-surface-*` / `--nova-text-*`），
并为暗色补覆盖（如果该 token 属于颜色/阴影/材质）。改完跑 `pnpm tokens:doc`。

## 3. 视觉方向（仍生效的部分）

- **中性优先 + 单一 accent。** 所有大平面是中性纸色，强调色只用于品牌/焦点/选中，
  禁止第二个彩色系；渐变只用于材质/极光，不用于常规表面。
- **密度优先。** 默认步进 8px（`--nova-space-8`），行高只有 24 / 28 / 32 三档
  （`--nova-row-*`）。不要用大留白制造"高级感"。
- **圆角按角色分档，不按大小。** `xs`（6）徽标/标签、`sm`（8）行内标记、`md`（12）密集行、
  `lg`（16）控件/输入/按钮、`xl`（24）页面最大表面、`full` 胶囊。
- **层级用平面阶梯 + 三级 elevation。** `sunken < base < raised < panel` 的单调性由
  `palette-guard` 钉住；停靠列不画阴影，只有浮层/输入卡使用 `--nova-elevation-*`。
- **动效克制。** 时长只有 `instant / fast(120) / base(180) / slow(260) / panel(200)`，
  缓动只有 `out / spring / inout`；入场不重播，页面不常驻运动。
- **排版。** 界面基准字号由 `theme.ts` 的 `--nova-content-font-size` 控制（12–17px，
  默认 14），正文/代码各自使用 `--nova-font-*` 与 `--nova-line-*` 阶梯。

## 4. Token 词汇表（自动生成）

token 分 11 个 sheet：`space`（间距/行高）、`radius`（圆角）、`surface`（平面/边框/交互填充）、
`text`（墨色）、`color`（强调色/语义色/图表）、`shadow`（elevation）、`glow`（光晕）、
`motion`（时长/缓动）、`typography`（字体/行高）、`diff`（diff 专用）、`shiki`（代码高亮）。
"何时用哪一族"看上面的视觉方向；具体值与明暗覆盖看下面的表。

## 5. 守卫规则（与脚本一一对应）

| 守卫 | 位置 | 管什么 |
| --- | --- | --- |
| 字面颜色 / 死类 / ANSI | `ui/test/style-guard.test.ts` | 组件源码不得出现 hex/rgb 字面颜色；每个模块定义的 class 必须在同目录源码里被字面使用；禁止 ANSI 转义 |
| 动效表挂载 / keyframes / reduced-motion | `ui/test/motion-guard.test.ts` | `design/index.css` 必须挂载 motion 表；共享 keyframes 与降级钳制存在；消息入场不重播 |
| 调色板不变量 | `ui/test/palette-guard.test.ts` | 平面阶梯两档单调；secondary 墨色达 WCAG AA；选中/悬停行不同色 |
| 字面量棘轮 | `scripts/ui-token-guard.mjs` | 五条规则（spacing/radius/shadow/duration/ease）的全仓总数上限 |
| token 表新鲜度 | `scripts/ui-token-doc.mjs` | 本文件 §4 与 `design/tokens/*.css` 一致 |
| 结构预算 | `scripts/structure-budget.mjs` | 单文件 600 行阈值（存量豁免只缩不涨） |

**棘轮的语义（不要误解）：** 基线记的是**上限**，不是当前债务。上限 = 当前 + 余量
（spacing +20 / radius +10 / shadow +6 / duration +12 / ease +12）。日常新增几个字面量落在余量里
不会红；只有整仓系统性上涨才红。确实要放宽时跑 `pnpm gates:update`，它逐条打印 `RAISED`，
commit diff 里看得见。

**红灯时先跑 `node scripts/ui-token-guard.mjs --explain`**：它列出违规行与该属性族可用的 token，
不用再靠猜。**严禁**为了过门禁去改守卫脚本、豁免表或断言。

## 6. 常见任务 recipe

### 6.1 新增一张卡片（工具卡 / 设置卡 / 右栏卡）

1. 在所属目录建 `X.tsx` + `X.module.css`（不新建全局 sheet）。
2. 外层用 `--nova-surface-raised` / `--nova-border-subtle` / `--nova-radius-lg`；
   内边距从 `--nova-space-*` 选；需要浮起才用 `--nova-elevation-panel`。
3. 标题用 `--nova-text-primary`，说明用 `--nova-text-secondary`，元信息用 `--nova-text-muted`；
   不要新造灰色。
4. 深色不写额外分支——表面/墨色 token 已在 `body[data-nova-dark]` 下覆盖。
5. 验证：`pnpm check`；开暗色看一遍；若卡片在对话流里，确认流式时不会每帧重建（见 §7）。

### 6.2 调整颜色 / 明暗

1. 只改 `design/tokens/` 里对应的 token；不要在组件里覆盖。
2. 亮色改 `:root`，暗色同步改 `body[data-nova-dark]` 块。
3. 跑 `pnpm vitest run packages/web/ui/test/palette-guard.test.ts`（阶梯单调 + AA 对比）。
4. 跑 `pnpm tokens:doc`（如果新增/改名了 token）。

### 6.3 新增动效

1. 时长/缓动只用 `--nova-dur-*` / `--nova-ease-*`。
2. 只动 `opacity` / `transform`；布局属性（width/height/top/left）不做过渡。
3. 共享 keyframes 加到 `design/motion.css`，组件 sheet 只引用名字；入场类动画不要挂在
   每次重挂载都会重播的节点上。
4. 跑 `pnpm vitest run packages/web/ui/test/motion-guard.test.ts`；开系统"减少动态效果"看一遍。

### 6.4 新增弹窗

1. 组合 `kit/Dialog`（遮罩/卡片/动画唯一实现），`panelRef` 交给 `shell/modal-layer` 的
   `useModalLayer` 管理 Escape/Tab/焦点返回。
2. 按钮用 `kit/Button`；不要在弹窗里再写一套遮罩或动画。
3. 宽度/内边距用 `Dialog` 的 `width`/`padding` 参数，不写新 CSS。

### 6.5 新增按钮

1. 先看 `kit/Button` 的三种 intent（secondary / primary / dangerOutline）够不够。
2. 图标按钮用 `kit/IconButton`；纯图标不要临时拼一个 `<button>`。
3. 只有 `kit/` 覆盖不了的形态（例如工具栏里的行内动作）才写局部 `<button>` + 目录 sheet，
   并复用 `--nova-row-*` / `--nova-shadow-*` / `--nova-surface-*`。
