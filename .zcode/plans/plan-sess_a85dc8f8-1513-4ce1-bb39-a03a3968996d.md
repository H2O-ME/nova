# NovaAgent 落地 SemVer 2.0.0 + 缺陷修复批（P1+P2+P3+结构重构）

版本策略（严格按 semver 2.0.0 规范）：
- 处于 **0.y.z 初始开发阶段**（FAQ 规则）：基线 **0.1.0**，本轮发行 **0.2.0**（次版本号递增、修订号归零），1.0.0 留待公共 API 冻结后
- 规范第 1 条 MUST：先书面定义公共 API（见第 0 步），否则升位规则无从判定
- 规范第 3 条 MUST NOT：已 tag 版本内容不可变——**绝不 amend/移动既有 tag**，一切修改走新版本；tag 用附注标签 `git tag -a vX.Y.Z -m "Release version X.Y.Z"`（规范 FAQ 对 v 前缀的定性：v 是 tag 名，版本号本体是无前缀的 X.Y.Z）
- 先行版本号规范支持但本项目暂不启用（单人维护无并行发布线）；如某轮想先发 rc 可用 changesets pre-release 模式（`0.2.0-rc.1`），流程内预留说明不实施

## 第 0 步：WIP 落地 + 公共 API 定义 + 基线 0.1.0
1. 修正未提交图片粘贴的误导性文案（`packages/cli/src/tui/keys.ts`）：不实现真多模态（涉及消息模型/投影/缓存波及，不成本比例），降级为诚实路径提示，代码注释与通知文案同步；vision 通路写入 roadmap。
2. 按现有风格提交这批 TUI 改动（`feat(tui): M7.4 …`），`pnpm verify` 绿。
3. **定义公共 API 并写入 AGENTS.md 新增"§10 版本与发布"**（规范第 1 条 MUST，形式：文档内严谨列表）：
   - 对外 API 面 = ① CLI 用法与参数（`nova`/`nova exec` flags、`--json` 事件 schema、退出码）② `~/.nova/config.json` schema ③ JSONL 会话日志 v2 格式与投影语义 ④ 插件 API（`PluginContext`/`ToolDefinition`/钩子签名）⑤ 各 `@nova-agent/*` 包的导出类型与函数
   - 升位映射：不兼容变更（如日志 v2→v3、插件 API 签名变更）= 0.y.z 期记入 RELEASE-NOTES 后升次版本，1.0.0 后升主版本；向下兼容新增 = 次版本；仅修正错误结果 = 修订号（x>0 时）
4. `git tag -a v0.1.0 -m "Release version 0.1.0"`。

## 第 1 步：changesets 机制 + 版本号合规校验 + TUI 显示版本
5. 引入 `@changesets/cli`（root devDep）+ `.changeset/config.json`：`@nova-agent/*` 全成员与 root 包组成 **fixed 锁步组**（monorepo 单版本号），`privatePackages: { version: true, tag: true }`；流程 = `changeset version` → commit → `changeset tag`（本地生成 `vX.Y.Z` 附注 tag，不依赖 CI；changesets 原生即"发布后不改内容、只向前发行"）。
6. 根脚本：`release`（version+commit+tag 一条龙）、`changeset`。
7. **运行时版本单一来源**：新增 `packages/cli/src/version.ts`（`createRequire(import.meta.url)('../package.json').version`，src/dist 双世界均解析到 `packages/cli/package.json`，结果缓存）；删除 `index.ts` 硬编码 `VERSION='0.1.0'`。
8. **TUI 显示版本号**（你的要求）：`buildSplash`（`packages/tui-view/src/splash.ts`）增 `version` 字段并在身份层渲染 `nova vX.Y.Z`；`tui-mode.ts`/`repl.ts` 调用点传入；REPL banner 与 `/session` 同源显示；splash 测试补断言。
9. **合规校验测试**：root 加 `scripts/verify-version.ts`（或 vitest 用例）：用官方 ECMAScript 正则校验 `^(0|[1-9]\d*)\.(0|[1-9]\d*)\.(0|[1-9]\d*)…$`（禁补零，规范第 2 条 MUST NOT）且 7 个 package.json 版本一致；挂进 `pnpm verify`。
10. 提交 + minor changeset。
