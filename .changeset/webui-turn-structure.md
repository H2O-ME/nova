WebUI 对话页与开屏对齐 deepseek-harness 的呈现结构：

- **轮次 header**：每轮一条「用时 X」全宽披露行（dsh TurnProcessNodeView 的移植）——运行中显示相位标签 + 滴答时钟（浅蓝扫光），落定后显示整秒时长并把本轮的过程行（思考/工具/job）折叠在 chevron 之后，默认收起；展开时在 header 下补一行本轮流量的完整读数（时钟 · 首 token · 吞吐 · 工具次数）。原独立的 `run_stats` 元数据行取消，数字由轮 header 与尾行分摊。
- **尾行用量 pill**：答案尾行（复制/分叉）新增「用量 N tok」按钮，点开本轮用量面板（模型 / 缓存命中 / 未缓存输入 / 缓存读取 / 输出，千分位精确数）——dsh TurnUsagePanel 的移植；最新落定轮的尾行常显，早前轮悬停显示。尾行按 dsh 规则带上消息时钟（`closing.time` 位）。
- **步骤语义标签**：推理行改读 dsh stepProcess 词汇——流式中「正在分析请求」+ 思考实时尾行，落定后「已完成分析」（原文收进展开体，不再拿首行英文当标题）。
- **上下文注入行折叠**：环境/项目文档注入行归入其所在轮次的过程组（首条 user 之前的注入挂到第一轮 header 之后），默认不再外露在转录顶部；无轮次可挂时仍独立成行，轨迹页不受影响。
- **统计条与占用表**：gauge 读数改 dsh `stats.counts` 模板「N 轮 N 步 · X tok/s」（轮与步之间不再插 `·`）；用量 pill 有计费输入即显示「缓存命中 N%」（无缓存读取为诚实的 0%）；ContextMeter 从工具条挪到卡片下方 dock 行与统计 pill 同排（dsh 的挂载位），触发器带百分比读数、环为中性色，面板条仍按占用严重度着色；`ready.usedTokens` 在回放旧会话时回落到日志最后一次 `run/stats` 的 promptTokens（内存锚点随进程而死，否则旧会话的占用表永远隐着）。
- **消息时钟**：当天的消息只显示 `HH:MM`，跨日/跨年才回填日期（dsh `formatMessageClock` 规则）。
- **开屏**：headline 从品牌字改为邀请语「今天想做点什么？」，星标重绘为四角星 + 轨道环，并新增工作区 chip 行（文件夹 + 工作区 basename，取自 `ready.rootDir`；无工作区菜单故为纯标签，不带假 chevron）；hero 阶段不再渲染 dock 行（无可读的数）。
- **侧栏**：无标题会话回落为「新会话」，与参照列一致。
