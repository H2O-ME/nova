**WebUI 对齐 deepseek-harness：撤掉移植过程中被放宽/丢弃的那几处**。用户点名的四个 class 都对应 dsh 源文件的**具体行**（`_dock`=`InputBar.module.css:22`、`_scroll`=`ChatView.module.css:22`、`_widthHandle`=`ConversationRoot.module.css:62`），所以逐个与原件对照即可定位偏差——四处都不是「样式微调」，而是移植时把一条规则改宽或整条丢掉。

- **`.widthHandle`（`_widthHandle_1x9yi_62`）不是多余控件**：dsh 里有同一个控件，问题在于我们的移植把命中条从 **10px 放宽到 40px** 并钉死 `z-index: 8`，同时**丢掉了它的 `onWheel` 转发**——于是它既过宽又压在内容之上，还把落到这条空隙上的滚轮事件吃掉了（读者在沟槽上滚不动页面）。三处都按原件改回：宽度恢复 `min(10px, calc((100% - var(--dsh-chat-content-width))/2 - 24px - 24px))`、`z-index: 0`（`[data-dragging]` 时才 8）、并补回 `wheelDeltaY` 转发到 `[data-conversation-scroll]`。`wheelDeltaY` 落在 `composer-measure.ts`（那里本来就是滚轮链式传递的归属地）而不是新开一份。
- **`.dock`（`_dock_1tfbq_22`）**：组合器根内边距 `8px` → `4px`（dsh 原值），并且 dock **无条件渲染**——dsh 的规则是 `.hero .dock:empty { display: none }`，靠 `:empty` 让无读数的英雄态自然居中；我们的条件渲染把它换成了一个隐式判断，于是 hero 态的间距凭空多一档。统计药丸 `StatsPills.module.css` 的 `.root` 也改回 dsh 的**收缩包裹**（`min-width:0; max-width:100%`，**无 padding/margin**）：此前它既占满整列又自带内边距。
- **`.scroll`（`_scroll_ckh0n_22`）/ 转录列**：`.root` 补 `overflow-x: visible; overflow-y: clip`（这是 dsh 让浮层可以横向溢出而纵向仍被裁的写法）；`.flowItem:empty` 由 `display:none` 改回 `height:0`（前者会让交替背景与列表语义丢一个节点）；`.callRow` 与 `.older button` 的圆角改用 `--dsw-radius-sm` 令牌而非字面量。
- **会话列表间距**：滚动条宽度 `8px` → **`5px`**（dsh 默认 `--dsh-scrollbar-width`）；行圆角 `8px` → `--dsw-radius-md` 并补上 `padding-inline-start: calc(8px + var(--dsh-workspace-indent, 0px))`（缩进此前整个缺失，所以分组内的层级完全看不出来）；`.sectionHeader` `12px` → `--dsw-radius-md`；原本只有 `.iconButton` 的 `:focus-visible` 规则改为 dsh 的 `.iconButton/.searchButton/.clearButton` 合并规则并改用 `--dsw-focus-ring-width` / `--dsw-focus-ring-color` 令牌——此前搜索与清除按钮**没有**焦点环。
- 一处注释被改成事实：`data-composer-stats` 在 dsh 里是**测试选择器**（全仓唯一消费者是 `apps/web/tests/message-actions.e2e.ts`），没有任何 CSS 规则依赖它。移植时给它编了一个「承重」理由，现已改回陈述事实。

**转录列（`_column_5960h_59` = dsh `ChatView.module.css:59`）的第二轮对齐**。逐个类名对照源文件后，偏差分三类——**多出来的**（移植时自己发明的）、**少掉的**（整条规则没搬）、**值不对的**：

- **多出来的四处已删除**。① `.column` 上的 `flex: 1 0 auto` 在 dsh 里**根本不存在**——它把列变成了按内容撑高的 flex 项，与 `.scroll` 的撑高打架；dsh 的列只有 `max-width` + `width: 100%` + `margin: 0 auto`。② 工具行 running 态有一条**自造的 `::after` 光带**（`dsh-tool-row-sweep`），dsh 里没有这件东西。③ 轮 header 另有一条**自造的 `background-clip` 渐变**（`.labelRunning` + `dsh-turn-status-shimmer`）和**第 5 个独立 `clock` span**；dsh 的 running 标题是**一个字符串**（`深度求索中，用时{duration}`）。④ `StateDot` 的实心态多一个 `::before` 光晕、ongoing 态是**自造的 8 格像素追逐**。
- **扫光收敛到一个原语**。dsh 只有 `TextShimmer` 一处实现 running 文字（`background-clip: text` 渐变扫过字形，`--dsh-text-shimmer-spread = 字数 × 8px`，`1.5s cubic-bezier(0.33,0,0.67,1)` 无限循环，`prefers-reduced-motion` 停用），被披露标题、工具行、命令行、过程组标题**共用**。新增 `shell/TextShimmer.tsx` + `.module.css` 逐字移植，工具行/命令行的 running 标题改走它——**下一条 running 文字不会再各自发明一份动画**。`ReasoningRow` 保留它自己的 `::after` 扫带（dsh 在那一处确实这么写），不是例外而是**照着源文件**。
- **`StateDot` 整体重写为 dsh 原件**：实心态 = 10px 槽位 + `inset: 20%` 的 6px `::after` 芯（**无光晕**）；ongoing = **14px 旋转 SVG 环**（`viewBox 0 0 24 24`，`spinnerTrack` + `spinnerArc` 双 r=9.5 圆），`dsh-state-dot-spin 1.5s linear infinite` + `dsh-state-dot-dash 1.5s ease-in-out infinite`（`stroke-dasharray 12 150 → 24 150 → 12 150`，offset `0 → -6 → 0`），颜色 `--dsw-alias-label-tertiary`；`syncSpinner()` 把 `animation.startTime` 钉到 0 做**相位锁定**（新挂载的环与既有环同步，而非各转各的）；降级动效保留静态弧（`18 150` / `-3`）而非把格子调暗。补上 `appearance: 'dot' | 'step'` 两种形态（`step` = 1.5px 环 + 完成勾）。
- **少掉的转录骨架已补**：`.frame`（`container-type: inline-size`，浮动控件据此查询，回转按钮已移出 `.scroll` 落到这里）、`.root[data-chat-following-tail] .scroll { overflow-anchor: none }`（贴尾时关掉引擎的滚动锚定，否则增长补偿会和跟随写入打架）、轮 header 的 `data-turn-process` / `-messages` / `-tool-calls` / `-subagents` 四个计数钩子、`role="status" aria-live="polite" aria-atomic="true"` 的隐形播报（键盘/读屏读者在折叠后仍被告知本轮在做什么）、点击后 `event.currentTarget.focus()`（折叠把焦点连同展开态一起丢掉是可达性缺陷）。
- **本轮过程组（dsh `ChatGroupSeat` 的 body）新落地**：一个回合的思考/工具/中途散文/上下文注入折叠进**一个有界盒**——`max-height: min(400px, 50vh)`、组内自滚、`overscroll-behavior-y: auto` 阻断链式滚动、`scrollbar-gutter: stable` 预留滚动槽，并在**还能继续滚的那一端**盖 24px 渐变遮罩（`fadeTop`/`fadeBottom`）。上限的意义是不让四十步的回合把自己的答案顶出屏幕；遮罩的意义是让「被裁掉了」与「到头了」可区分——没有它，被裁的行只像渲染故障。**运行中的回合不设限**：组内步骤就是读者正在等的进展，裁掉它们等于藏起进度。组内节奏 8px、展开后回到 16px（`--dsh-chat-flow-gap` 的 dsh 原义）。
- **中途散文归入步骤**：一个回合里**最后一段落定的 text 是答案**，它之前的 text 是「走到答案路上写的话」，与工具行同属一次动作、一并折叠（dsh `answerStep` 规则）。此前它们会被当成并列的多个答案排在转录里——这是「多点啥」的一处实质来源。折叠判定在**整条流上**先算好再分组，所以进程组被装箱也不会算错答案行的 8px 节奏。
- **用量面板改为 portal**：面板此前是转录内的绝对定位 `div`，而转录 `.root` 有 `overflow-y: clip`——尾行靠近滚动口上沿时面板会被**裁掉**（dsh 用 `createPortal` 正是为此）。改用既有的 `shell/anchored-popover.ts`（fixed 定位 + 视口夹取 + 外点关闭）。触发器尺寸改回 dsh 原件（28px 高、`6px 8px` 内边距、`--dsw-radius-sm`、`calc(secondary - 1px)` 字号、15px 图标），补 `.root + .root { margin-left: -6px }` 相邻回扣与 `@media (max-width: 480px)` 收成纯图标。`MessageIconActions` 补 `data-clock`（尾端动作 17px 而非 15px）、`.endInfo` 簇（gap 8 / margin-left 8 / tertiary）与 `.timeEnd` 的字号颜色。
- **命令行改走披露行**（dsh `GenericCommandCard`）：此前是自造的 flex 行 + 状态点，现复用 `DisclosureRow` + `TextShimmer`，多行输出作为展开体——与工具行同一词汇，不再是「第二个家族的工具行」。
