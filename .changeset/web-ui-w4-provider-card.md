### W4：把供应商卡的编辑器从内联闭包里拆出来

`ProviderSection.tsx` 里有一个约 200 行的 `renderEditor` 闭包，和「草稿表 /
写盘协议 / 探针状态」挤在同一个函数里——四件事一个函数，764 行。这次拆的是
**职责边界**，不是为了压行数：

- **`ProviderCardEditor.tsx`**（255 行，新）：一张卡的编辑器体——连接字段、
  请求参数、模型清单、卡脚。只接收值和回调，不知道草稿怎么存、整份清单怎么写。
- **`provider-draft.ts`**（33 行，新）：`ProviderDraft` 类型。名册和单卡编辑器
  都要用它，编辑器不该为了拿一个类型去 import 名册。
- **`ProviderSection.tsx`**：764 → 594 行，回到 600 阈值以下，`gates:update`
  **自动把它从豁免表移出**（豁免 7 → 6），无需任何手工登记。

#### 顺手修掉一个我自己引入的语义偏差

搬家时把 `probeFail` 从 `{ message?: string }` 拍平成了 `string`。探针的拒绝帧
可以不带 detail，原写法是「渲染外框、不渲染详情行」；拍平后传 `''` 会多出一个
空 `<p>`，把卡片撑高——**一个静默失败的探针会改变卡片高度**。已改回传整个帧、
由组件判断 `message !== undefined`。
