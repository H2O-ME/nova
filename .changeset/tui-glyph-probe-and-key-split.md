**字形按真机探针选定 + 键位彻底归一**（M10 批7b，验证驱动）：在真实 Windows Terminal（zh-CN / Cascadia Mono）里逐字形打印标尺行做探针，测得两件事——

- `⧉`(U+29C9) **该字体没有字形**，终端画成十六进制豆腐块：粘贴 chip 与子代理行一直显示成"坏字符"。换成探针确认存在的单格宽字形——chip 用 `▤`(U+25A4，"一叠行")、子代理用 `◈`(U+25C8，嵌套)，并新增导出 `CHIP_MARK` / `SUBAGENT_MARK` 作为唯一来源。同时证实：本项目用的框线/导轨/箭头字形全是单格宽（宽度表与终端一致），全角 `！：` 是双格宽（表也一致）。
- **审批弹窗不再自带键位说明行**：`↑↓ 选择 · Enter 确认 · Esc 拒绝` 与底部快捷键条逐字重复，正是设计语言要消掉的"哪儿都在说"。弹窗只留内容（头部 / diff 预览 / 三个选项 / 一句授权语义），键位全部交给快捷键条，并补上**随光标出现的条件键位**：停在「总是允许」且命令确有多词可收窄时印 `←→:调授权词数`，停在「拒绝」时印 `打字:补理由 │ ⌫:删字`（`HintState` 新增 `approvalScope` / `denyTyping`）。

**破坏面**：`buildApprovalPopup` 少 1-2 行提示行（弹窗行数变短）、粘贴 chip 与子代理行的标记字形变更。
